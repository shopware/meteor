## Usage

Use this page for a section that has no records yet, such as the promotions of a new shop. Instead of an empty list or table, the [**Empty State**](/components/empty-state) explains what the section holds and offers the action that creates the first record.

Show the empty state only while there are no records at all. When a search or a filter finds nothing, keep the list with its search and filters, so people can change them.

The empty state is centered with `centered`, and the page centers it in the whole content. Its `button` slot holds a plain primary [**Button**](/components/button), instead of the default button with its icons. In your application, the shell is shared by all pages, so copy the **Page** into a route and the shell into your root component once. Replace `createPromotion()` with the dialog or the route that creates the first record.

## Components

- [**App**](/components/app) for the shell of the application
- [**Page**](/components/page) for the header with the breadcrumb and the content
- [**Empty State**](/components/empty-state) for the explanation
- [**Button**](/components/button) for the action

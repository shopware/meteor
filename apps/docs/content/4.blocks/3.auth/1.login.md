## Usage

Use this page as the entry point of an application that needs its own login. It shows the logo above a card with the form, and the link to reset the password below it.

The page fills its container, so render it outside of [**App**](/components/app), for example in a route without the shell. Replace the logo with your own and the timeout in `login()` with the request to your authentication endpoint. The template shows how the page looks while it waits and after a failed attempt: try it with any username and password.

## Components

- [**Text Field**](/components/text-field) and [**Password Field**](/components/password-field) for the credentials
- [**Checkbox**](/components/checkbox) to stay logged in
- [**Button**](/components/button) to submit the form
- [**Banner**](/components/banner) for a failed attempt
- [**Card**](/components/card) for the form, with its loading state while the request runs
- [**Link**](/components/link) to reset the password

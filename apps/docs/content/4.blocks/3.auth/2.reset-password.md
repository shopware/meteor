## Usage

Use this page for the "Forgot password?" link of the [**Login**](/blocks/auth/login). People enter the email address of their account, and the page confirms that a link is on its way. The confirmation is the same whether an account exists or not, so the page doesn't reveal which email addresses have one.

The page fills its container, so render it outside of [**App**](/components/app), for example in a route without the shell. Replace the logo with your own and the timeout in `requestLink()` with the request that sends the link. The page that sets the new password, which the link leads to, is not part of this template.

## Components

- [**Email Field**](/components/email-field) for the email address
- [**Button**](/components/button) to submit the form
- [**Card**](/components/card) for the form and the confirmation, with its loading state while the request runs
- [**Text**](/components/text) for the heading and the explanation
- [**Link**](/components/link) back to the login

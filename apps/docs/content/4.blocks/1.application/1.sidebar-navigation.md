## Usage

Use this shell for applications with more than a handful of sections. The navigation stays visible next to the content and holds nested sections. On narrow screens, **App** turns the navigation into a drawer that opens from the header.

Render the shell once, in the root component of your application, and the router view in its `content` slot. Mark the current page in the navigation with `active`, or pass `is-active` to **Nav** to compare its rows with the current route. Replace the `placeholder-slot` with the pages of your application.

## Components

- [**App**](/components/app) for the shell
- [**Nav**](/components/nav) for the navigation
- [**Page**](/components/page) for the page in the content

## Usage

Build your own header when [**App Header**](/components/app-header) doesn't fit your application, for example for an application without a main navigation. In this template, the [**Brand**](/components/brand) at the start opens a menu with the signed-in user and what concerns the account, such as the settings and the logout, so the header needs no user menu. A search across the whole application sits in the center, and a create action and the notifications at the end.

The menu is an [**Action Menu**](/components/action-menu) that opens from a button around the **Brand**, with a [**User**](/components/user) at its top. Replace the brand, the user and the entries with your own.

A custom header handles its own layout and responsive behavior, which **App Header** would otherwise do for you. Here, the search takes the space of the create action on narrow screens. When you add a `navigation` or a `sidebar` to the shell, place an [**App Panel Trigger**](/components/app#triggers-in-a-custom-header) for each in your header, so the panels can be opened once they are closed or turned into drawers.

## Components

- [**App**](/components/app) for the shell
- [**Brand**](/components/brand) for the name of the application
- [**Action Menu**](/components/action-menu) and [**User**](/components/user) for the menu of the account
- [**Search**](/components/search) for the global search
- [**Button**](/components/button) and [**Icon**](/components/icon) for the actions
- [**Page**](/components/page) for the page in the content

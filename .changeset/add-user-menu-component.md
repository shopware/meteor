Add `mt-user-menu`: a menu for the logged-in user, for example in the `footer` slot of `mt-sidebar`. It shows the avatar, name and optional `role` of the user and opens a menu with a logout entry that emits `logout`. Further entries can be added through the default slot, and an optional `version` is shown at the bottom of the menu.

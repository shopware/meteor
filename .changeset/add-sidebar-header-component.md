Add `mt-sidebar-header`: the header for the `header` slot of `mt-sidebar`. It shows a logo, a `title` with an optional `subtitle` and a button that emits `collapse`. The logo defaults to the Shopware logo and can be replaced with the `logo` slot. The collapse button can be hidden with `collapsible` and its accessible name set with `collapse-label`.

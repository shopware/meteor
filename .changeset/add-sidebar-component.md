Add `mt-sidebar`: a vertical layout container with a fixed `header` and `footer` slot and a default slot for a navigation component. The navigation area scrolls on its own when it is taller than the sidebar and shows scroll shadows at the top and bottom to indicate hidden content. The width can be set with the `width` prop and the accessible name with `aria-label`.

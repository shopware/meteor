Add `mt-sidebar-footer`: the user menu for the `footer` slot of `mt-sidebar`. It shows the avatar, name and optional `role` of the logged-in user and opens a menu with a logout entry that emits `logout`. Further entries can be added through the default slot, and an optional `version` is shown at the bottom of the menu.
